# Auth feature

Nơi chứa mọi thứ liên quan xác thực (Phase 1 §4):
- `components/` – trang `/login`, `ProtectedRoute`, …
- `hooks/` – `useAuth()`
- `services/` – gọi `/api/auth/*`
- `store/` – global auth state (zustand)
